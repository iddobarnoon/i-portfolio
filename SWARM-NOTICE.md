# Swarm engine provenance

The construction engine and renderer were recovered from the published JavaScript at https://github.com/califa/swarm-site/blob/main/assets/index-BcWSe1v5.js (blob ad9a977cbf5030e07325af66f43caea607da2d82).

The repository publishes built assets, without a project license or source maps in its file tree. Recovery does not supply a license. Confirm reuse permission with the author before publishing a derivative.

Bundled React was removed and replaced with imports from this project's existing React dependencies. The scheduler, generator-driven editor actions, cursor physics, and rendering were retained. The scene, colors, brand mark, and real links were adapted to Iddo Barnoon's portfolio.

Recovered names are descriptive replacements, not the author's original source names. Randomized movement and typing mean repeated runs are not pixel-identical.
